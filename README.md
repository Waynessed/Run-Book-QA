# RunbookQA

A local engineering support assistant over fictional Northstar runbooks. Python/FastAPI, PostgreSQL/pgvector, MiniLM retrieval, Ollama Qwen 2.5 1.5B and React.

Start: `./scripts/bootstrap.ps1`, then open http://127.0.0.1:5174. See [current state](docs/current-state.md), [demo](docs/demo.md), [walkthrough](docs/walkthrough.md) and [implementation log](docs/implementation-log.md) for actual verification status.

No paid services, real credentials, public deployment or autonomous actions. Answers need source review. CPU defaults; first launch downloads models. Only UI 5174 and API 8081 bind to localhost.
