# RunbookQA implementation guidance

Read RUNBOOKQA_HANDOFF.md, docs/current-state.md and docs/implementation-log.md before changes. Maintain those records and docs/walkthrough.md as code changes. Distinguish implemented code, executed tests, measured model runs and assumptions. Never invent evaluation results or hide model failures. Keep held-out cases out of tuning and normal CI. Preserve user changes. User authorized development commits and pushes in this session.
