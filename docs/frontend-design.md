# Frontend design

Palette: canvas #edf2f7, investigation panel #e3edf7, ink #203349, action #195a9f, borders #c5d2df, focus #df9626. Segoe UI provides familiar incident-workbench typography. Left-aligned question and evidence columns collapse on mobile. The main visual device is the evidence rail beside each claim; controls stay quiet and functional. No decorative image or complex settings. Loading copy states model latency; errors preserve the real failure. Keyboard focus, source version drift and empty evaluation state are explicit.
